# Erste Schritte

## In zwei Minuten starten

1. Öffne mit `.komet` die Einstellungen.
2. Wähle unter Komet › Übersicht eine Voreinstellung und bestätige mit Enter.
3. Blende mit F7 das HUD ein. Beurteile Ruckler anhand der Framezeiten.
