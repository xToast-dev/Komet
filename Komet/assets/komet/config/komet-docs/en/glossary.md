# Glossary

## Performance

- **Frame time**: Time in milliseconds to produce a frame. High outliers are visible as hitches.
- **GC**: The .NET runtime reclaims managed memory. Some collections pause game threads.
- **JIT**: The .NET runtime compiles methods into machine code.
- **Tessellation**: Builds triangles from blocks and models.

## Rendering

- **Pass**: A drawing step such as terrain or a fullscreen effect.
- **Framebuffer**: A target for color, depth or other outputs.
- **Define**: A shader compile-time constant.
- **Uniform**: A value passed to a running shader program.
- **SPIR-V**: An intermediate format for Vulkan shaders.
