Komet versions of your own shader files go here: config/komet/shaders/<file> stands in for shaders/<file> while Komet
runs (likewise config/komet/shaderincludes/<file> for shaderincludes/<file>). The normal file must exist too. Without
Komet, the game never uses the files in this folder.
For a game shader you replace, use assets/game/config/komet/shaders/<file>.
Guide in game: Komet's options › Modding › "Your mod for Komet", step 5.
