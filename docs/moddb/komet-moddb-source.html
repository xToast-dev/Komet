WHAT IS KOMET?

A performance mod for Vintage Story 1.22

Komet makes Vintage Story run smoother. It changes how the game draws the world and loads chunks, so you get steadier frame rates, fewer stutters while exploring and lower memory use — without changing gameplay.

Just drop it in
Put the ZIP in your Mods folder. No launch options, no extra tools.
Works everywhere
Singleplayer and multiplayer. Komet is a universal mod: install it on your PC, on a server, or both. A server can run without it.
Safe to try
If something doesn’t work on your PC, Komet switches back to the game’s normal renderer by itself. Removing the ZIP undoes everything.
Everything adjustable
Komet adds its own page to the game’s settings, so you can turn each improvement on or off.

FEATURES

What changes when you install Komet

Faster graphics with Vulkan

On Windows and Linux Komet draws the world with Vulkan, a modern graphics interface that many GPUs handle better. If your PC can’t run it, the game’s normal OpenGL renderer takes over automatically.

Smoother exploring

Far-away terrain uses less detail, nearby chunks sharpen first and new chunks load spread over several frames — so flying or running into new land hitches less.

Less memory

Komet keeps chunk data more compactly, which helps on large view distances.

Better settings menu

Search all settings by name, pin favourites and pick a menu style.

Performance overlay

Press K to see your FPS and short frame-time spikes, so you know what costs performance.

Good to know

All features have a switch in Settings › Komet. The defaults are chosen for your PC on first start.

INSTALL OR UPDATE

Takes about a minute

1 · Download

Download the Komet ZIP from this page (or use 1-click install).

2 · Put it in your Mods folder

Don’t unzip it. If you have an older Komet ZIP there, delete it first — and a separate “Komet SDK” ZIP too, if you ever installed one.

3 · Start the game

That’s it. Komet picks sensible settings for your PC. To change them, open Escape › Settings › Komet.

Uninstall

Delete the ZIP. Your worlds are not changed by Komet.

FAQ & PROBLEMS

Quick answers

Do I need Komet on the server?

No, but you can. Komet is universal: with it on your PC you can join any server. If a server installs it, the game downloads it for players when they join.

Does it work with my other mods?

Usually yes. Some mods are known to work especially well — see the Mods tab.

Black screen, flicker or a crash?

Open Settings › Komet and set the renderer to OpenGL. If the game doesn’t start at all, remove the Komet ZIP and report the problem.

Lower FPS than before?

Turn single features off in Settings to find the one that doesn’t suit your PC, and tell us which one it was.

Report a problem

Please include your Komet version, your other mods and whether you use Vulkan or OpenGL. The log file client-main.log helps a lot.

COLOUR GRADING

Change exposure and saturation of the finished frame

The split shows the original beside the graded image.

Left: original · right: with the shader. Illustrative scene.

The pass changes brightness in exposure stops, then adjusts saturation.

c *= exp2(myshadersExposure);
float luma = dot(c, vec3(0.2126, 0.7152, 0.0722));
c = mix(vec3(luma), c, myshadersSaturation);

DISTANCE HAZE

Fade distant terrain into a cool haze

Foreground and sky keep their colour.

Left: original · right: with the shader. Illustrative scene.

The pass uses the depth buffer to blend only distant terrain.

float d = texture(depth, uv).r;
float far = smoothstep(0.990, 0.9995, d)
          * (1.0 - step(0.99999, d));
color = vec4(mix(c, dayHaze, far * myshadersHaze), 1.0);

KOMET.JSON

assets/<modid>/config/komet.json · no code needed

Komet reads the file from every enabled mod at world join and builds a page from settings. A define rebuilds your shaders; a uniform updates live.

// assets/mymod/config/komet.json
{
  "settings": [
    { "key": "haze", "label": "Distance haze",
      "type": "slider", "min": 0, "max": 1, "step": 0.05,
      "default": 0.5, "uniform": "mymodHaze" },
    { "key": "fog", "label": "Haze pass",
      "type": "switch", "default": 1 }
  ],
  "passes": [
    { "id": "haze", "fragment": "shaders/haze.fsh",
      "when": "fog" }
  ]
}

KAPI 1.0

C# API in Komet.Core.dll — Komet stays optional

  1. Reference the player’s Komet.Core.dll with Private="false"; don’t ship it.
  2. Name KAPI types only in a bridge class, so your mod loads without Komet.
  3. Call the bridge from StartClientSide when komet is enabled.
using Komet.Api;

internal static class KometBridge
{
    public static void Start(ModSystem system, ICoreClientAPI api, Action startOwn)
    {
        var komet = Kapi.Connect(system, "1.0");
        if (komet is null) { startOwn(); return; } // the log says why

        komet.Shaders.Uniform("mymodHour", () => api.World.Calendar.HourOfDay);
        komet.Options.Page("My mod")
             .Switch("Warm picture", () => Config.Warm, v => Config.Warm = v);

        var fx = komet.Shaders.TryAddPasses(new KapiPass("grade", Config.GradeSource));
        if (!fx.Active) startOwn(); // fx.Error says why
    }
}

Good to know

Don’t list Komet in dependencies unless your mod can’t work without it.

Every connected mod shows on Developer › Connected mods with its registrations and cost.
