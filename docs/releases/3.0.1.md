# Komet 3.0.1

Bug-fix release for Vintage Story 1.22. Replace `komet_3.0.0.zip` in your `Mods` folder with `komet_3.0.1.zip`.

## Fixes

- Vulkan-only (Lean): when the GPU stalls and Vulkan stops mid-world, OpenGL cannot get the world's textures back and
  only the GUI is drawn over a black screen. Komet now says so in chat and as an in-game error: leave the world and
  join it again (the next join uses OpenGL safety mode).
- A failed Vulkan submission now logs the real `VkResult`, and a stalled swapchain acquire is reported as such instead
  of "returned 0".
- The frame bridge no longer allocates new copies on a window or render-size change while the GPU does not go idle.
